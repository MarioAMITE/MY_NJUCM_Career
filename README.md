# 个人项目合集

本仓库汇总了我学习与实习期间完成的部分项目，涵盖软件开发、数据分析和软件测试等方向。各项目的详细介绍见对应目录下的文档。

## 项目列表

### 1. 非酒精性脂肪肝健康管理APP

- **技术栈**：C#（.NET Framework 4.7.2 / Windows Forms）、MySQL
- **简介**：面向非酒精性脂肪肝（NAFLD）患者的 Windows 桌面端健康管理应用，涵盖商城、论坛、智能饮食分析、医患咨询、个人健康档案等 5 大功能模块。
- **要点**：MySQL 数据库设计（10 张数据表、20 余项患者特征）、分层架构（实体层 / 数据访问层 / 服务层 / 表现层），预留智能饮食图像识别与运动监测服务接口。

### 2. 社区医院结算系统（本科毕业设计）

- **技术栈**：Java、Spring Boot 3.4、MyBatis-Plus、MySQL、Vue3 + Element Plus、JWT
- **简介**：社区医院费用结算系统，支持管理员 / 医生 / 患者三种角色的权限管理，实现药品费用与医疗费用两类结算单的下单、医保报销计算、缴费与导出打印。
- **要点**：前后端分离、JWT 登录认证、MyBatis-Plus 数据访问、EasyExcel 导出。

### 3. LLM Agent 大规模转录组表型整理工作流

- **技术栈**：Python、R、Shell、Linux 集群（Slurm/PBS）、多 LLM 接口（DeepSeek / Qwen / ChatGPT）
- **简介**：面向感染性疾病亚型分类研究的技术附件，构建自动化 Agent 管道，利用 LLM 解析异构 SRA / GEO 元数据，完成 500+ 数据集、约 70,000 样本、20,000 基因的外周血转录组表型信息结构化提取。
- **要点**：Prompt 工程驱动的 LLM-as-Agent 策略、元数据解析与分组逻辑精炼、感染类型自动归类。

### 4. 软件测试实习材料

- **技术栈**：Python（Selenium）、浏览器性能测试
- **简介**：浏览器稳定性与性能测试实习材料，对 LiteView 浏览器与 Chrome 进行对比测试。
- **要点**：TOP100 网址打开速度测试、CPU 与内存占用对比、稳定性测试、测试用例与评分标准整理。
