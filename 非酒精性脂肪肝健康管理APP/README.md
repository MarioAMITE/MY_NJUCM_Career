# 非酒精性脂肪肝健康管理APP

针对非酒精性脂肪肝（NAFLD）患者的健康管理需求设计开发的 Windows 桌面端应用，提供健康商城、患者论坛、智能饮食分析、医患咨询、个人健康档案等核心功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| 商城 | 健康产品浏览、搜索、加入购物车 |
| 论坛 | 患者交流、发帖、回帖 |
| 智能AI | 饮食描述分析，预留图像识别接口 |
| 咨询 | 医患在线消息交流 |
| 个人中心 | 个人档案、生化指标、报告导出 |

## 技术栈

- 语言 / 框架：C#（.NET Framework 4.7.2，Windows Forms）
- 数据库：MySQL（MySql.Data 8.0.33）
- 架构：分层架构（表现层 / 服务层 / 数据访问层 / 实体层）

## 系统架构

采用分层架构，层间依赖单向、职责清晰：

- **Entities**（实体层）：患者档案、行为日志、商品、订单、帖子、咨询消息等数据实体
- **DAL**（数据访问层）：MySQL 连接助手 + 各实体仓储接口
- **Services**（服务层）：饮食分析、图像识别、运动监测、智能咨询等服务接口
- **Forms**（表现层）：主界面 + 5 大功能窗体

## 数据库设计

`Sql/schema.sql` 定义 10 张数据表：

| 表 | 说明 |
|----|------|
| user | 用户（患者 / 医生 / 管理员） |
| patient_profile | 患者电子档案（20+ 项特征字段） |
| behavior_log | 行为日志（饮食 / 运动 / 用药 / 睡眠 / 体重） |
| product | 商城商品 |
| orders / order_item | 订单与订单明细 |
| post / reply | 论坛帖子与回帖 |
| consult_message | 医患咨询消息 |
| ai_analysis_record | 饮食分析记录 |

其中患者电子档案覆盖生化指标（ALT、AST、GGT、血脂、血糖、尿酸等）与体格指标（BMI、腰围）等 20 余项特征；行为日志表支撑饮食、运动、用药依从性、睡眠、体重等日常记录。`Sql/seed.sql` 提供脱敏演示数据。

## 目录结构

```
├─ Form1.cs                  主界面
├─ Program.cs                程序入口
├─ Entities/                 数据实体
├─ DAL/                      数据访问层
├─ Services/                 服务接口
├─ Forms/                    功能窗体
├─ Properties/               资源与设置
├─ Sql/
│  ├─ schema.sql             建表脚本
│  └─ seed.sql               演示数据
└─ App.config                应用配置（含数据库连接串）
```

## 快速开始

### 运行

1. 使用 Visual Studio 2017 及以上打开 `非酒精性脂肪肝健康管理APP.sln`。
2. 首次构建自动还原 NuGet 依赖（MySql.Data）。
3. 编译运行，进入主界面后点击按钮进入各功能模块。

### 初始化数据库（可选）

1. 在 MySQL 中依次执行 `Sql/schema.sql` 与 `Sql/seed.sql`。
2. 修改 `App.config` 中连接串的账号、密码。

> 未连接数据库时界面可正常浏览；数据读写功能需数据库就绪后启用。
